PAINT FRAMES - Microsoft Paint on Windows 11

NEW IN v0.3: DIFFERENT FPS FOR EACH TRACK
The Layered animation tab has an FPS column. Set each track to 1-12 FPS.
For example, 2 FPS holds each frame for half a second; 8 FPS advances
eight times per second. Set FPS to 0 to use Default FPS below the editor.
The Default FPS control also sets the speed for Single loop mode.

Tracks run on the same elapsed-time clock at independent speeds. Start
after waits for the parent's cycles at its own FPS: three frames repeated
three times at 2 FPS finish after 4.5 seconds. F6/F7 step between scheduled
changes. Paint may skip intermediate frames if it cannot keep up.

Track FPS values are saved in setup XML files. Older v0.2 setups still
load and use their saved default speed for tracks without an FPS field.

LAYERED ANIMATION
Open the Layered animation tab to animate several tracks together or
chain one loop after another. Click "Your example" for this setup:

  Track     Layers   Cycles   Start after   When done
  Loop 1    1-6      3        (blank)       Hide
  Loop 2    1-3      1        Loop 1        Hide
  Loop 3    4-8      0        Loop 2        Hide

This needs at least eight Paint layers. Numbers are positions in Paint's
top-to-bottom layer list: 1 is the top layer, regardless of its name.
Loop 1 plays three complete times, then Loop 2 once, then Loop 3 forever.
Cycles=0 means forever. An outgoing track set to Hide disappears.

Leave Start after blank on multiple tracks to animate them together.
Use Hold last to keep a finished track's last frame visible.
Use 1+7,2+8,3+9 to make frames containing several layers at once.
Layers not used by enabled tracks keep their original visibility.
Each track can have its own FPS. Paint's layer order controls stacking.

Repeat whole sequence restarts all finite tracks; uncheck it to stop at
the end. Save setup / Load setup stores tracks and their FPS values in an
XML file, not the artwork. Keep the same Paint layer order when loading.
Editing a track pauses playback; the next step restarts the preview.
The Single loop checklist only controls the Single loop tab.

SINGLE LOOP (ORIGINAL MODE)

1. Open your drawing in Paint and open the Layers panel.
2. Double-click PaintFrames.exe. No installation or AutoHotkey required.
3. In the helper, UNCHECK any layers you do not want to animate.
   Checked layers become frames. Unchecked layers keep their original
   visibility: visible ones stay visible, hidden ones stay hidden.
   For a permanent background, show that layer in Paint before starting
   the preview, then uncheck it in the helper.
4. Click Paint, then use:

   F7  Next frame (first press starts at the TOP checked layer)
   F6  Previous frame
   F8  Play / pause
   F9  Stop and restore the original layer visibility

Each checked paint layer is one complete frame. Only one checked layer is
shown at a time, together with any visible excluded layers. The last frame
loops back to the first. The separate background swatch is left as it was.
The shown frame is also selected for drawing. The checklist follows the
top-to-bottom order in Paint, even if Paint's layer names count backwards.

Changing a checkbox pauses playback and restores the original visibility;
press F7 to start with the new selection. To change whether an excluded
layer stays visible, press F9, set its eye button in Paint, then start again.
Exclusions last while the helper is open. They are not saved into the image.

The small helper window has the same controls, a First frame button,
and a playback speed control. Playback pauses when you switch to another
app. Its speed depends on how quickly Paint updates its layers.

The shortcuts are intercepted only while Microsoft Paint is active.
On some laptops you may need Fn+F6 / Fn+F7 / Fn+F8 / Fn+F9.

Keep the Layers panel open. After adding, deleting, or reordering layers,
click Re-scan. It preserves exclusions for layers it still recognizes.
Restore before changing the layer structure if you want to preserve the
previous visibility state. The next preview records the current visibility
as its restoration point.

Closing the helper restores the visibility and selection saved at the
start of the preview when the same layers are still available. It does not
save, export, delete, merge, or modify the pixels of your artwork. Any
drawing you do while using it stays in the selected frame. This is a live
preview helper; it does not export GIFs or videos.

SOURCE
PaintFrames.cs, AnimationTimeline.cs and TrackEditor.cs contain the source.
Build.cmd rebuilds it with the .NET Framework compiler included with Windows.
No administrator privileges, downloads, or security-setting changes needed.
